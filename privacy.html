MEHdictation Privacy Policy

Last updated: 1 October 2026

MEHdictation is a local-first dictation application for Windows and Android. Speech recognition and dictated content are processed on the user's own device rather than being sent to a cloud transcription service.

In short: microphone audio is never included in MEHdictation Sync. Dictionary entries, Templates and aggregate usage statistics can sync end-to-end encrypted between devices. Private is on by default: while it is on, transcript history stays local. When the user explicitly turns Private off, cleaned transcript history may also be synchronised end-to-end encrypted. Application names and window titles are not included in transcript sync.

Information MEHdictation accesses

MEHdictation accesses the microphone when the user starts dictation. It may also process text created by the user and locally stored application data including dictation history, Dictionary entries, Templates, preferences, hotkey settings and aggregate usage statistics.

Local speech processing

On Windows, speech recognition is performed locally using the MEHdictation speech-recognition runtime and model. On Android, MEHdictation uses Android on-device speech recognition. Dictated audio and resulting text are not sent by MEHdictation to a remote transcription or language-model service.

Optional MEHdictation Sync

MEHdictation Sync is optional and must be enabled by the user. When enabled, Dictionary entries, Templates and aggregate usage statistics can synchronise between the user's Windows and Android installations. Sync payloads using the current Private Sync channel are encrypted on the user's device before transmission so the service stores encrypted content rather than plaintext Dictionary, Template or transcript data.

Microphone audio is never included in sync. Transcript history is included only for dictations made while Private is off. Synced transcript entries contain cleaned text plus limited metadata needed for history/statistics such as timestamp, word count and duration; application names and window titles are not included.

Storage

Dictation history, settings and other application data are stored locally on the user's device. When sync is enabled, encrypted synchronisation data for Dictionary entries, Templates and aggregate statistics is stored by the MEHdictation sync service so it can be retrieved by the user's other devices. If Private is off for a dictation, an encrypted cleaned-transcript history entry may also be stored for cross-device retrieval.

Sharing and third parties

MEHdictation does not sell dictated content or user data and does not disclose dictated audio or clinical text to advertisers or data brokers. The optional Private Sync service is used only to provide the user-requested synchronisation function. Distribution through the Microsoft Store is also subject to Microsoft's own Store, account, acquisition and diagnostic processes, which are governed by Microsoft's privacy terms rather than this policy.

Analytics, advertising and tracking

MEHdictation does not include advertising and does not use third-party advertising trackers. Aggregate usage statistics are kept locally and, only when Private Sync is enabled, may be included in the user's encrypted sync data for cross-device statistics.

Clinical and sensitive information

MEHdictation may be used in clinical environments. Private is on by default and is the intended mode for clinical or other sensitive dictation. The Private setting is device-local, so users should check the visible Private state on the device they are using. Users remain responsible for complying with employer policies, professional duties and applicable information-governance requirements.

User control

Microphone access is controlled through operating-system permissions and by starting or stopping dictation. Private can be switched directly from dictation mode; the state chosen at the start of a dictation governs that dictation. Private is on by default. Sync itself is optional and can be disconnected. Users can manage local history, Dictionary entries and Templates within MEHdictation and can uninstall the application at any time.

Changes to this policy

This policy will be updated if MEHdictation's data handling changes materially.

Support and privacy questions
