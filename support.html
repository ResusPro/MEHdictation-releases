MEHdictation Support

MEHdictation is currently distributed on a limited, direct-link basis. Support is provided on a best-effort basis rather than as a commercial service.

Before reporting a problem

Check the Version & updates section inside MEHdictation and make sure you are using the current release. If a keyboard or mouse dictation trigger stops responding after standby, allow the app a few seconds to re-arm its input hook; if necessary, quit the tray application completely and reopen it.

Report a problem

For reproducible bugs, installation problems or compatibility issues, use the public MEHdictation release issue tracker. Please avoid including patient-identifiable information, dictated clinical text or screenshots containing confidential data.
